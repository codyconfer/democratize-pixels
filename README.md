### Bundled app replacements

> links are f-droid, if a listing isn't linked, it can be found in accrescent

- replace voice typing with transcribro

- replace google keyboard with [FUTO keyboard](https://keyboard.futo.tech/) _available in f-droid with alt repo_

- replace pixel launcher with lawnchair _available in f-droid with Izzy alt repo_

- replace chrome with ironfox

- replace google maps with organic maps

- _bonus_ BeauTyXT for text/markdown editing, auxio for local audio playback, and molly: a signal client with at-rest encryption

- replace pixel clock with [clock](https://f-droid.org/packages/com.best.deskclock)

- replace pixel weather with [breezy weather](https://f-droid.org/packages/org.breezyweather)

- replace pixel calculator with [calculator m3](https://f-droid.org/packages/com.vagujhelyigergely.calculatorm3)
_bonus_ [scientific calculator](https://f-droid.org/packages/com.jherkenhoff.qalculate)
